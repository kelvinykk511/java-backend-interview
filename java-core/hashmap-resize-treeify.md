# HashMap 擴容與樹化

**問題**：HashMap 點定位桶？幾時擴容、幾時變紅黑樹？

- hash = h ^ (h >>> 16)，下標 = hash & (n-1)，容量必為 2 的冪。
- 負載因子 0.75，size > 容量*0.75 擴容為 2 倍；元素要麼留原位要麼移去「原位+舊容量」（看 hash & oldCap）。
- 鏈長 ≥ 8 且容量 ≥ 64 才樹化，否則先擴容；≤ 6 退化回鏈表。
- JDK8 尾插法，解決 JDK7 頭插並發擴容成環；但仍非線程安全（丟數據），並發用 ConcurrentHashMap。
- **陷阱**：key 可變對象改了字段 → hashCode 變，get 唔返；預估大小用 `new HashMap<>(n/0.75+1)`。
