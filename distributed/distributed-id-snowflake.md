# 分布式 ID：Snowflake 與時鐘回撥

**問題**：訂單 ID 點生成？Snowflake 遇到時鐘回撥點算？

- 方案：DB 自增（單點、可分段步長）、號段模式（Leaf-segment，批量取一段、雙 buffer）、UUID（無序、索引差）、Snowflake（1 符號 + 41 毫秒時間戳 + 10 機器 ID + 12 序列）。
- Snowflake 優點：本地生成、趨勢遞增（B+ 樹插入友好）、每機每毫秒 4096 個。
- 時鐘回撥：小幅（幾 ms）等待追上；大幅拒絕發號 + 告警；或用「上次時間戳」繼續遞增（借未來時間）；預留回撥位。
- 機器 ID 分配：靠 ZK/DB/K8s 序號註冊，避免兩台撞號 → 重複 ID。
- **陷阱**：ID 暴露業務量（可推算單量）；JS Number 只有 53 位精度，前端要用字串。
