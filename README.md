# Java Backend Interview Warm-up

Kelvin 的 Java 後端面試溫習庫。每天早上會新增一輪短溫習，內容按主題分類。

## 目錄

| 目錄 | 主題 |
|------|------|
| `java-core/` | 集合、基礎 API、語言特性 |
| `concurrency/` | 多線程、鎖、JUC |
| `jvm/` | 內存模型、GC、類加載 |
| `spring/` | Spring / Spring Boot |
| `mysql/` | MySQL / InnoDB / 事務 / 索引 |
| `redis/` | Redis 緩存與高可用 |
| `kafka-mq/` | Kafka / 消息隊列 |
| `distributed/` | 分佈式基礎 |
| `networking/` | HTTP / 網絡 |
| `sessions/` | 每日溫習原文檔（按日期） |

## 怎麼用

1. 早上先看當天 `sessions/YYYY-MM-DD.md`
2. 再翻對應主題目錄裡的精煉筆記
3. 每個主題檔通常有：面試問題 → 答法 → 常見追問

## 約定

- 筆記以**面試可口述**為準，短而準
- 繁體中文為主
- 每日例行：約 09:37（Asia/Ho_Chi_Minh）
