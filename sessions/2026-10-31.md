# 2026-10-31 Java warm-up

## 上次 drill 答案（2026-10-30）

題：自己寫嘅 `BeanPostProcessor`（統計 Bean 初始化耗時）構造器注入咗 `OrderService`，啟動 log 出 `Bean 'orderService' ... is not eligible for getting processed by all BeanPostProcessors`，之後事務好似失效。點解？點改？

- **點解**：BPP 要喺 `registerBeanPostProcessors` 階段**提早**實例化。佢構造器要 `OrderService`，Spring 只好連 `OrderService`（同佢成條依賴鏈）一齊提早創建。嗰陣仲有啲 BPP 未註冊完，`OrderService` 就錯過咗佢哋，所以出呢個 warning。如果錯過嘅係負責包 AOP / 事務代理嘅（auto-proxy creator 或者事務 advisor 未就緒），`OrderService` 就係個**冇代理嘅原始對象**，`@Transactional` 自然唔生效。
- **點改**：
  - BPP 入面**唔好直接注入業務 Bean**；真係要用就 `ObjectProvider<OrderService>` / `@Lazy`，用嘅時候先攞。
  - BPP 保持「純」，用 `static @Bean` 聲明，唔依賴其他業務 Bean。
  - 統計啟動耗時其實唔使自己寫 BPP：Spring Boot 有 `BufferingApplicationStartup` + Actuator `/actuator/startup`。
  - 見到 "not eligible for getting processed by all BeanPostProcessors" 就當係紅旗，逐條查。
