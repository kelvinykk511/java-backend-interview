# 2026-11-02 Java warm-up

## 上次 drill 答案（2026-11-01）

題：worker 線程用 BIO `socket.getInputStream().read()` 等數據，`shutdownNow()` 停唔到。點解 interrupt 冇用？點令佢停得到？

- **點解**：`interrupt()` 只係設標誌 + 喚醒「響應中斷」嘅阻塞（`sleep`/`wait`/`join`/`LockSupport.park`/NIO `InterruptibleChannel`）。傳統 `java.net.Socket` 嘅 `read()` 唔係可中斷 I/O，標誌設咗但線程繼續卡喺系統調用。
- **點令佢停**：
  - `socket.setSoTimeout(…)`：read 定時拋 `SocketTimeoutException`，loop 入面檢查 `Thread.currentThread().isInterrupted()` 再決定退出。
  - 停機時由另一條線程 **`socket.close()`**，read 即刻拋 `SocketException` → 例如覆寫任務嘅 cancel / 停機 hook 去 close。
  - 改用 NIO `SocketChannel`：佢係 `InterruptibleChannel`，interrupt 會關閉 channel 並拋 `ClosedByInterruptException`。
  - 補充：JDK 21 虛擬線程上，阻塞喺 Socket I/O 時被 interrupt 會關 socket 並拋 `SocketException`，但平台線程照舊唔得。

詳見 [線程中斷](../concurrency/thread-interrupt.md)。
