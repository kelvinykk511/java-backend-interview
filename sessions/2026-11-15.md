# 2026-11-15 Java warm-up

## 上次 drill 答案（2026-11-14）

題：對帳 job 用 offset 循環掃當天成交，同線上共用主庫：

```sql
SELECT * FROM trades
WHERE trade_time >= ? AND trade_time < ?
ORDER BY id
LIMIT :offset, 1000;  -- offset 每次 +1000
```

跑到後半段越嚟越慢，主庫 CPU 同 buffer pool 讀暴增，線上 P99 一齊差。同時交易服務剛從 G1 切到 JDK 21 `-XX:+UseZGC`（**冇**開 `ZGenerational`），撮合高峰偶發請求變慢，GC 日誌出現 allocation stall，堆長期貼近 `-Xmx`。

問：(1) 呢條 OFFSET 循環點解會越掃越慢？你會改成點樣掃？(2) 點解未開分代嘅 ZGC 容易 stall？同 G1 的 Mixed／Full GC 有何不同？你會點改？

- **OFFSET 越掃越慢**：`LIMIT offset, 1000` 每次都要沿索引走完 **offset + 1000** 行，再把前面嘅 offset 丟掉。offset 由 0 去到 10 萬，後半段等於重複掃已經走過嘅前綴，CPU 同 buffer pool 讀線性上升，同線上搶主庫就打高 P99。延遲關聯呢度幫唔大：job 本身就要掃大批行，瓶頸唔係回表，而係重複走過 offset。
- **點改**：改 keyset，唔好循環加 offset。若 `id` 自增同時間大致單調，先把時間範圍換成 id 範圍，再 `WHERE id > :lastId AND id <= :maxId ORDER BY id LIMIT 1000`。否則用 `(trade_time, id)` 組合鍵做 keyset（時間同 id 一齊作為游標），避免 `trade_time` 範圍再 `ORDER BY id` 導致 filesort 或掃太多。對帳打從庫／離峰，唔好同線上共用主庫掃表。
- **非分代 ZGC 容易 stall**：JDK 21 只開 `UseZGC` **預設係非分代**（分代要顯式 `-XX:+ZGenerational`；23+ 先預設分代）。非分代要把短命對象同長命對象一齊並發回收，撮合高峰分配快，回收追唔上就 **allocation stall**——分配線程卡住等回收騰空間。堆長期貼近 `-Xmx`，餘地更少，更易 stall。
- **同 G1 Mixed／Full 唔同**：G1 係 STW 停下來做 Young／Mixed，追唔上就 evac failure 甚至 Full GC，一次停頓較長。ZGC stall 唔係一次長 STW Mixed，而係分配路徑上等待並發回收。用戶體感一樣係毛刺，但唔好用調 `MaxGCPauseMillis` 嗰套思路去「調 stall」。
- **點改**：JDK 21 打開 `-XX:+ZGenerational`（或升 23+）；堆留出餘量，唔好讓活數據貼滿 `-Xmx`；再查分配速率同大對象。Stall ≠ 零停頓。

## 今日 drill

下單入口登記咗兩個 Filter + 一個 Interceptor：

1. `SignatureFilter`（普通 `Filter`，唔係 `OncePerRequestFilter`）：用 wrapper 讀 body 驗 HMAC，然後 `chain.doFilter`。
2. `RateLimitFilter`：Redis Lua 令牌桶，key=`rl:{apiKey}`，10 token/s、桶容量 10；Redis 超時時 **fail-open**。
3. `UserInterceptor`：`preHandle` 把 userId 放入 `ThreadLocal`，`afterCompletion` 先 `remove`。

開盤後出現三種現象：

(1) 少數「簽名正確」嘅請求偶發驗簽失敗，access log 見到同一個 `requestId` 進咗 Filter 兩次；有啲請求嘅 429 次數好似多扣咗。
(2) 一條下單接口回 `DeferredResult`／`CompletableFuture`，另一條喺 Controller 入面 `@Async` 發通知——出現 `UserContext.get()` 為 null，亦有用戶串單（看到別人的 userId）。
(3) 限流 Redis 一個 slot CPU 100%，同時 Redis 超時率約 5%，撮合被打爆，做市商實際過咗遠超 10/s 的單。

問：(1) Filter 點解跑兩次？點改？(2) ThreadLocal 喺異步下點解會空或串數據，`afterCompletion` 救唔救到？(3) fail-open + 單 key 令牌桶喺開盤點解會失守，你會點改？
